# ココナラ案件ツール

ココナラの募集案件を探して、評価し、提案文を作り、提案フォームに入力するまでを手伝うツールです。
ご自身のパソコン（Mac / Windows）で動かします。

| ステップ | このツールがすること | コマンド |
|---|---|---|
| ① 案件検索 | キーワード検索のページから新着案件を集め、1件ずつ詳しく読む | `run` |
| ② 案件の選別 | 報酬・作業時間・スキルの合い方で点数を付ける。無報酬・内容が不明確・修正が多すぎる案件は外す | `run` |
| ③ 優先順位付け | 点数の高い順に並べ、A / B / C のランクを付ける | `run` |
| ④ 提案文の作成 | 案件ごとに提案文を作る（AIを使う場合は、案件に合わせて書く） | `run` |
| ⑤ 応募準備 | 提案フォームを開き、提案文と金額を入力する | `apply` |
| ⑥ 応募 | **送信ボタンだけは、ご自身で押します** | － |

### 送信を自動にしていない理由
- 送る前に、金額・納期・文章を必ず目で確認するため
- ココナラは違反行為を機械で見つける仕組みを使っています。大量の自動送信はスパムと見られて、アカウントが制限されるおそれがあります

## 準備（最初の1回だけ）

ターミナル（Mac は「ターミナル」アプリ）で、1行ずつ実行します。

```bash
# 1. Python が入っているか確認（3.10 以上ならOK）
python3 --version

# 2. このフォルダに移動
cd career/coconala

# 3. このツール専用の環境を作って、必要なものを入れる
python3 -m venv .venv
source .venv/bin/activate          # Windows は  .venv\Scripts\activate
pip install -r requirements.txt
playwright install chromium        # Google Chrome がある場合は不要ですが、入れておくと安心です

# 4. ブラウザでココナラにログイン（ログイン状態はこのパソコンに保存されます）
python coconala.py login
```

2回目からは、`cd career/coconala` と `source .venv/bin/activate` のあとに、下のコマンドを使います。

### AIで提案文を書く場合（任意）
キーがなくても動きます（そのときはテンプレートの提案文になります）。

1. https://console.anthropic.com で API キーを作る
   - Claude の月額プランとは別で、使った分だけ支払います
   - 目安：1件あたり 約0.05〜0.1ドル。1回の実行で最大8件（`config.yaml` の `max_reviews`）
2. `.env.example` をコピーして `.env` という名前にし、`ANTHROPIC_API_KEY=` の後ろにキーを貼る

## 使い方

### 毎日の流れ
```bash
python coconala.py run
```
1. 新着案件を探して、評価と提案文の作成をします（数分かかります）
2. 結果のページ（`output/…/report.html`）がブラウザで開きます
3. ターミナルに候補の一覧が出るので、応募したい案件の **番号** を入れます
4. ブラウザで提案フォームが開き、提案文と金額が入力されます（青い枠）
5. 内容を確認・修正して、**送信ボタンを自分で押します**
6. ターミナルで `y` を押すと「応募済み」として記録され、次からは表示されません

### そのほかのコマンド
| コマンド | すること |
|---|---|
| `python coconala.py list` | 前回の候補をもう一度表示して、応募の準備をする |
| `python coconala.py apply 2` | 前回の一覧の2番の案件で、応募の準備をする |
| `python coconala.py apply https://coconala.com/requests/1234567` | 自分で見つけた案件で、評価・提案文・応募の準備をする |
| `python coconala.py run --all` | 前に見た案件も、もう一度評価する |
| `python coconala.py run --no-ai` | AIを使わずに実行する |
| `python coconala.py run --show` | ブラウザの画面を見せながら実行する |

## 自分に合わせて変える

### `config.yaml`
| 項目 | 内容 |
|---|---|
| `search.keywords` | 検索するキーワード |
| `search.extra_urls` | ココナラで条件（カテゴリ、募集中のみ、新着順など）を選んだあとのURLを貼ると、そのページも見ます |
| `categories` | 第1〜第5候補の分野。`weight` が優先度、`keywords` が「合う」と判断する言葉、`hours` が作業時間の目安 |
| `target_hourly_yen` | 目標の時給（手数料22%を引いたあと） |
| `min_budget_yen` | これより安い案件は外す |
| `avoid` | 入っていたら外す言葉（無報酬、修正無制限、LINEへの誘導など） |
| `score_weights` | 点数の付け方（スキル・時給・受注しやすさ・わかりやすさの割合） |
| `display_name` | 提案文で名乗る名前 |

### `profile.md`
提案文に使う経歴です。ココナラのプロフィールと書き方をそろえてください。
**ここに書いていない経験や数字は、提案文に入りません**（話を盛らないため）。

### 点数の見方
| 点数 | 内容 |
|---|---|
| スキル | 得意分野とどれだけ合うか（第1候補ほど高い） |
| 時給 | 予算の中央 × (1 − 手数料) ÷ 作業時間。目標の時給で100点 |
| 受注しやすさ | 提案数が少ないほど高い（2件以下で100点） |
| わかりやすさ | 本文の長さ、予算・納期が書いてあるか |

AIを使う場合は、AIが本文を読んで「スキル」「作業時間」「わかりやすさ」を付け直し、
「応募する / 検討 / 見送り」の判断と理由も出します。

## うまく動かないとき

ココナラの画面のデザインが変わると、読み取れなくなることがあります。

- **「案件が見つかりません」と出る**
  ブラウザでココナラの「仕事を探す」を開き、条件を選んで表示されたURLを `config.yaml` の `extra_urls` に貼ってください。
- **予算や提案数が「不明」になる**
  `python coconala.py debug https://coconala.com/requests/1234567` を実行すると、
  `output/debug/` に画面の写真と読み取った内容が保存されます。これを見せてもらえれば直せます。
- **ページが開けない・ログインを求められる**
  `--show` を付けて画面を見ながら実行するか、`python coconala.py login` でもう一度ログインしてください。
- **Google Chrome が見つからないと出る**
  自動で Chromium に切り替わります。`playwright install chromium` を実行しておいてください。

## 気をつけること
- ページを開く間隔は4〜8秒にしています。サイトに負担をかけないよう、短くしないでください。実行は1日1〜2回が目安です
- 提案文に、メールアドレス・LINE・URLなどの連絡先は書かないでください（ココナラの規約で禁止）
- `.browser-profile/`（ログイン状態）と `.env`（APIキー）は他の人に渡さないでください。GitHubには上がらない設定にしています

## ファイルの説明
| ファイル | 内容 |
|---|---|
| `coconala.py` | コマンドの入り口 |
| `config.yaml` | 設定 |
| `profile.md` | 提案文に使う経歴 |
| `app/search.py` | ① 案件検索 |
| `app/parse.py` | 案件ページから予算・提案数・期限などを読み取る |
| `app/score.py` | ② 選別 と ③ 優先順位 |
| `app/ai.py` / `app/template.py` | ④ 提案文（AI / テンプレート） |
| `app/apply.py` | ⑤⑥ 提案フォームへの入力 |
| `app/report.py` | 結果のページ（HTML）とCSV |
| `tests/` | テスト（ココナラ風の模擬サイトで動作を確認） |

テストの実行: `pip install pytest` のあと `python -m pytest`
